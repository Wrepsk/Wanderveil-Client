# Passport artwork provenance

Created for Wanderveil on 18 October 2026 with OpenAI's built-in image-generation tool. These are original generated material/illustration assets, with no input reference images, copied game textures, third-party logos, or upstream UI artwork. They are distributed as project assets under the repository's existing license; this is not a claim of exclusive copyright in generated imagery.

| File | Purpose | Dimensions |
| --- | --- | --- |
| `book-open.png` | Blank physical book material, alpha shadow, leather, sewn binding and paper | 1536 × 1024 |
| `book-cover.png` | Blank closed leather cover with alpha shadow | 1024 × 1536 |
| `demo-portrait.png` | Invented adult traveler portrait; no real player/known character | 1086 × 1448 |
| `stamp-atlas.png` | Three original engraved demo motifs, transparent ink | 2172 × 724 |

Generated files are retained unchanged. Text, captions, logical pages, and controls are separate live rendering. Cover/collection previews are visual targets, not evidence of awarded stamps or page-turn implementation. The heading fonts have separate Adobe/SIL OFL licensing in `assets/fonts/SourceSerif4-LICENSE.md`, bundled with releases.

The exact prompts are in [generation-prompts.md](generation-prompts.md). Source Serif 4 Regular/Semibold files are unmodified from Adobe's `source-serif` revision `80d3f8894c09c937bebfa9011247d2e1c79fd6f4`, `TTF/`. No asset conversion pipeline or generated-image service is required to build the client.
