# Gridania visual studies

Created on 18 October 2026 with OpenAI's built-in image-generation tool using the [recorded prompts](generation-prompts.md). The user chose Gridania as the first edition. These files are review resources, not embedded runtime assets; the plugin's existing root PNG/font resources remain unchanged.

| File | Dimensions | Purpose |
| --- | --- | --- |
| `cover.png` | 1024 × 1536 | Forest-green leather and botanical blind embossing; edit of the existing project-owned blank cover |
| `cover-plum.png` | 1024 × 1536 | Initial plum colorway; retained as input to the transparency refinement, not selected in the gallery |
| `cover-plum-cutout.png` | 1024 × 1536 | Selected plum artwork colorway with cleaned surrounding alpha; not a procedural recoloring mask |
| `crest.png` | 1254 × 1254 | Separate gold lily/paired-serpent heraldic interpretation |

| `map-overhead.png` | 1086 × 1448 | Selected overhead schematic map study, not validated game geography |

Outputs retain their generated RGBA pixels unchanged. Text, identity fields, captions, map cartouche lettering, and signature glyphs are separate native rendering. The existing fictional portrait and stamp atlas are reused. No downloaded image, extracted game texture, reference screenshot, or third-party font file was supplied to generation.

## Research references

- [Official Gridania city description](https://na.finalfantasyxiv.com/a_realm_reborn/sp/world/cities/gridania/): woodland/waterway context and wooden architecture.
- [Community Gridania reference, Flag section](https://ffxiv.consolegameswiki.com/wiki/Gridania#Flag): lily, golden field, and entwined-serpent heraldic description. This is secondary reference material, not an artwork license or an exact-flag validation.

The generated banner/crest are original stylized interpretations, not official reproductions. FINAL FANTASY XIV setting names and heraldic concepts remain attributable to Square Enix. Project-authored contributions use the repository's existing license; no exclusive copyright claim is made for generated imagery, and that license does not grant rights in third-party intellectual property. These studies do not establish release-ready geography or exact heraldry.

The native gallery loads local Windows Segoe UI and Segoe Script as preview-only font surrogates; neither is redistributed. Signature text is the invented sample name Ari Vale, not a real person's signature. Signature input/storage is not implemented. Bundled Source Serif 4 retains its existing Adobe/SIL OFL license.
