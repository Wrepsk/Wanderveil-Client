# Asset reservation

| Directory | Intended content |
| --- | --- |
| `icons/` | Plugin/section/action icons |
| `textures/` | Subtle book/paper/surface textures |
| `stamps/` | Original or licensed curated demo stamp art |
| `fonts/` | Only fonts with documented distribution rights |

No raster production artwork has been added. The sample goat asset/content reference was removed; the shell draws an original placeholder compass in `src/Wanderveil/UI/CompassMark.cs` with no image loader or external asset dependency. Prefer ordinary UI primitives before introducing large texture packs. Record author, source, license, dimensions, intended use, and attribution in [third-party notices](../THIRD_PARTY_NOTICES.md). Keep unlicensed reference screenshots out of shipped assets.
